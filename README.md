حول دفتر فلوس بقيد مزدوج.

## التشغيل

### متطلبات النظام

| الأداة | النسخة | ملاحظة |
|---|---|---|
| [uv](https://docs.astral.sh/uv/) | ‏0.11 فأحدث | يدير الاعتماديات وينزّل بايثون نفسه — لا تحتاج pip ولا venv يدوي |
| Python | ‏3.13 فأحدث | `uv sync` ينزّلها لو لم تكن عندك |
| PostgreSQL | ‏17 | **إلزامية.** الاختبارات ترفض العمل على أي محرّك آخر — انظر أسفل |
| Redis | ‏7 (اختياري الآن) | لـCelery لاحقاً؛ لا شيء في الفيز 001 يحتاجه |

جهّز القاعدة والمستخدم مرة واحدة (الدور يحتاج `CREATEDB` لأن Django ينشئ قاعدة
اختبار منفصلة ويحذفها بنفسه):

```sql
CREATE ROLE haraj LOGIN PASSWORD 'haraj' CREATEDB;
CREATE DATABASE haraj2 OWNER haraj;
```

### ثلاثة أوامر

```bash
cp backend/.env.example backend/.env      # ثم عدّل SECRET_KEY وDATABASE_URL
cd backend && uv sync
uv run python manage.py migrate && uv run python manage.py runserver
```

بعدها: توثيق الـAPI على `http://127.0.0.1:8000/api/docs/`، ولوحة الإدارة على
`/admin/` (أنشئ حساباً بـ`uv run python manage.py createsuperuser`).

### الاختبارات والجودة

```bash
cd backend
uv run pytest
uv run ruff check . && uv run ruff format --check .
```

ثلاثة أشياء تستحق أن تُعرف قبل أول تشغيل:

1. **الاختبارات على PostgreSQL فقط.** `backend/conftest.py` يوقف الجلسة برسالة
   مفهومة لو كان المحرّك غير postgres (الدستور، المادة ٤-٢). لا تُغرِ نفسك
   بـSQLite: الدفتر يقف على `SELECT ... FOR UPDATE` وقيود `CHECK` وفهارس فريدة
   جزئية، وSQLite لا يقدّم أياً منها.
2. **الإعدادات ترفض العمل بمفتاح افتراضي خارج DEBUG** وترفع `RuntimeError` عند
   الاستيراد. `.env.example` فيه `DEBUG=True` فيمرّ محلياً؛ أي تشغيل بإعدادات
   إنتاج يحتاج `SECRET_KEY` حقيقياً في البيئة.
3. **لو تشتغل بالتوازي مع غيرك على نفس خادم PostgreSQL،** أعطِ نفسك قاعدة
   خاصة قبل `pytest` حتى لا تتصادم قاعدة الاختبار مع قاعدة زميلك:
   `export DATABASE_URL=postgres://haraj:haraj@127.0.0.1:5432/haraj2_<اسمك>`

> `ops/compose.yaml` (تاسك T003) و`justfile` (تاسك T005) لم يُكتبا بعد؛ حتى
> ذلك الحين التشغيل بالأوامر أعلاه مباشرةً.

## لأي وكيل AI يعمل هنا

1. اقرأ الدستور، ثم `spec.md` و`plan.md` للفيز، ثم خذ **تاسكاً واحداً**.
2. `[P]` يعني أن التاسك مستقل ويمكن تنفيذه بالتوازي. بدونها التسلسل مقصود.
3. لا تدّعِ نتيجة لم تشاهدها. لو لم تشغّل الاختبارات، قل ذلك.
4. عند الانتهاء: حدّث حالة التاسك، شغّل الاختبارات، واذكر ما لم يُنفَّذ ولماذا.
5. لو خالف spec الدستور — توقّف واسأل. لا تصلح الدستور بنفسك.
