# الفيز 007 — API العميل

## الهدف

عقد واحد موثَّق ومختبَر يغطي كل ما يحتاجه تطبيق العميل — يُبنى قبل التطبيق، لا
معه.

## المبدأ الحاكم

**العقد أولاً.** يُكتب مخطط OpenAPI ويُتفق عليه قبل أي شاشة، فيبني الـFlutter
على شيء ثابت بدل أن يُطارد تغييرات الخلفية.

## نطاق الفيز

- المصادقة: جوال + OTP، رموز وصول وتحديث
- الملف الشخصي: عرض وتعديل، الهوية الوطنية، بيانات الشركة والعنوان الوطني
- المزادات: قائمة، تفاصيل، مركبات، بحث وترشيح
- المزايدة: وضع، خفض بتأكيد، سحب، مزايداتي
- المحفظة: الرصيد بدلائه، الحركات، الشحن، الاسترداد
- المشتريات والفواتير والسداد
- الإشعارات وتسجيل جهاز
- المفضّلة

## قواعد

1. كل نقطة في المخطط بمثال حقيقي، وكل خطأ موثَّق برمزه.
2. لا نقطة بلا اختبار للنجاح **ولأهم فشل** فيها.
3. لا كتابة مالية إلا عبر `money.services`.
4. الأرقام العشرية كنصّ في JSON، لا كـfloat.
5. الأخطاء بالشكل الموحّد من الفيز 001، والرسالة عربية جاهزة للعرض.
6. الأوقات ISO-8601 بـUTC؛ التطبيق يحوّل للعرض.
7. المحفظة تعرض الدلاء **مفصَّلة**: متاح، محجوز لمزاد، مقفول لمستحقات — لا رقم واحد.

## الأمان

| القاعدة | لماذا |
|---|---|
| كل نقطة تتحقق من الملكية بالمستخدم من الرمز، لا من مُعامل | ثغرة IDOR على المحفظة في v1 |
| تحديد معدّل على OTP بكل مساراته | كل مسار OTP بلا حدّ = بوابة رسائل مجانية |
| تغيير الجوال يحتاج تأكيد الرقمين | مسار استيلاء على الحساب في v1 |
| الهوية الوطنية تُثبَّت مرة، والقفل يسري على القيمة **الصحيحة** فقط | ليتمكن من أدخل خطأً من تصحيح نفسه |
| مبالغ التأمين من الخادم لا من الطلب | تلاعب بالمبلغ في v1 |
| تسجيل جهاز الإشعارات يُربط بالمستخدم من الرمز | IDOR على FCM في v1 |

## معايير القبول

| # | المعيار |
|---|---|
| G1 | `/api/schema/` يولّد OpenAPI صالحاً يُستهلك بمولّد عميل |
| G2 | كل نقطة لها اختباران على الأقل: نجاح وأهم فشل |
| G3 | لا نقطة تُرجع بيانات مستخدم آخر — اختبار IDOR لكل نقطة تحمل معرّفاً |
| G4 | كل مبلغ في كل استجابة نصّ عشري، لا رقم عائم |
| G5 | المحفظة تعرض الدلاء مفصَّلة ومجموعها يطابق الدفتر |
| G6 | حدود المعدّل مفعّلة ومختبَرة على OTP والمزايدة |

## يعتمد على قرار المالك

**Q5 — هل يبقى موقع ويب للعملاء أم التطبيق فقط؟** لو بقي الويب، يحتاج هذا الفيز
واجهة ويب أيضاً وليس API فقط.
