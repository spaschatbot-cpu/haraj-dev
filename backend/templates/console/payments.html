T931 `unlocalize` على كل مبلغ: يُعرض كما يخزّنه الدفتر (المادة ٣-٢) — وهذه الشاشة تُقارَن سطراً بسطر بكشف البنك أو بتقرير أودو، والتنسيق يجعل المقارنة مستحيلة. **ولماذا تبويبان.** كانت الشاشةُ تعرض `PaymentIntent` وحدَها — أي **محاولاتِ** الدفع عبر البوّابة — واسمُها في الشريط «إدارة المدفوعات». وعلى الإنتاج: محاولاتٌ **صفر**، وفي الدفتر **١٣٬٨٦٣ قيدَ سداد**. فالموظّفُ يفتح الشاشةَ فيقرأ «لا دفعات» وقد دُفعت. فالافتراضيُّ ما قُيِّد — وهو ما تعرضه شاشةُ v1 (`payments/index.php`) بأعمدتها: المصدر · رقم العميل · الاسم · رقم الفاتورة · المبلغ · اسم الدفعة · الحالة. والمحاولاتُ تبويبٌ ثانٍ لأنها تجيب سؤالاً آخر — «دفعتُ ولم يصل» — ومحاولةٌ فاشلةٌ ليست دفعة، فخلطُها بالمقيَّد يجعل الجدولَ لا يُجمَع. **ولا تحكّمَ في الصفّ، وهو الفرقُ الوحيد عن v1 المقصود.** هناك «تحكم» يعدّل حالةَ الدفعة واسمَها ويحذفها — وهذه قيودُ دفترٍ مزدوج: تصحيحُها يكون **بقيدٍ عاكس** يُكتب باسم صاحبه، لا بتحرير صفٍّ قديم. وزرٌّ يعدّل مبلغاً مُقيَّداً هو بعينه ما يجعل الدفترَ لا يتّزن. {% endcomment %} {% block title %}إدارة المدفوعات{% endblock %} {% block heading %}إدارة المدفوعات{% endblock %} {% block actions %} {% if which == "recorded" and may_record %} {% endif %} تصدير إلى إكسل {% endblock %} {% block content %} {% comment %} تبويبان روابطُ لا أزرار: يُنسخان ويُفتحان في تبويبٍ جديد. {% endcomment %}
