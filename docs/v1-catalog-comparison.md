# كتالوج السيارات — مقارنة v1 ⇄ v2

المصدر في v1: `admin_v2/vehicles/catalog` →
`src/Controllers/Admin/VehicleCatalogController.php` + `src/Views/Admin/vehicles/catalog.php`.
في v2: `apps/console/catalog.py` (`vehicle_catalog`, `vehicle_bids`) +
`templates/console/vehicle_catalog.html` (وجزئياته).

الهدف: **نفسُ الداتا ونفسُ العمليات**، بعرضٍ أنظمَ وأسرع، وبلا أعطال v1
المقيسة.

## الفلاتر (نفسُها، بلصائقها فوق كل حقل)

بحث داخل النتائج · حالة المزاد · من/إلى تاريخ إدراج السيارة · من/إلى تاريخ
المزاد · تطبيق الفلاتر · مسح الفلاتر. في v2 كلُّها في القاعدة (`WHERE`) لا فلترةٌ
على قائمةٍ في الذاكرة كـ v1.

## العمليات (كلها مربوطةٌ بالقاعدة)

| العملية | v1 | v2 |
|---|---|---|
| بحث | JS على النصّ | `q` في القاعدة (شاصي/لوحة/اسم/لوت/رقم مزاد) |
| الصور | نافذة تجلب `/api/v1/vehicles/{id}/images` | نافذة `vehicle-images?modal=1` (رفع + عرض) |
| الفاتورة | `<iframe>` صفحةٌ كاملة لكل ضغطة | **سند دفع** يُملأ من `data-*` بلا رحلة خادم (`_invoice_voucher.html` + `after_sales.js`) |
| عرض | نافذة تفاصيل | نافذة `vehicle-detail?modal=1` |
| المزايدات | نافذة تجلب `analytics/.../vehicle-bids` | نافذة `vehicle-bids` — من زايد/بكم/متى/حال المزايدة، مرتّبةٌ بالأعلى |
| إضافة يدويًا | نافذة `store` | نافذة `vehicle-new?modal=1` (نموذج v2 الكامل، ٢٠ حقلاً) |
| تحديد الكل | زرّ | زرّ + مربّع رأس |
| إنشاء مزاد من المحدد | ينتقل لـ`auctions/create?vehicle_ids=…` | ينتقل لـ`auction-new?vehicle_ids=…`، يعرض **السيارات المحددة**، ويستوعبها بعد الحفظ (بقفل الفاتورة الحيّة) |
| تحديث | reload | reload |
| تصدير إكسل | — | زرٌّ يصدّر كلّ المطابق للمرشّحات |

## أعطالُ v1 المقيسة التي لا تُنقَل

- **الفاتورة تُحسب من الدفعات** لا من كلمة أودو المكتوبة مرّةً (عطل T809):
  `derive_invoice_state` + `residual_of`.
- **الانضمامُ على `auction_id`** كان يضرب المركبات × الفواتير (٢٦٠×٢٧٩≈٧٢ ألفاً)
  فيُسقط الصفحة بـ500؛ v2 استعلامٌ فرعيٌّ لآخر فاتورة.
- **`(int)'تويوتا' = 0`** يُقارَن بـ`id` فيرجع آلافاً؛ v2 لا يقارن نصّاً برقم.

## قرارٌ مفتوحٌ للمالك

عمود «شركة التأمين»: يعرض الحقل، لكن دلالة v1 تخلط المؤمِّنَ بمصدر المركبة.
الفصلُ (حقلُ «مصدر» وحقلُ «مؤمِّن») قرارُ المالك قبل الاعتماد عليه في تقرير.
