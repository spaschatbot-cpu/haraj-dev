## معيار «منتهٍ» — لا يتغيّر

1. اختبارٌ **يفشل بدون التغيير**، ومُثبَتٌ بإفشاله لا بالادّعاء.
2. الحزمة خضراء على PostgreSQL بإعدادات الإنتاج — لا SQLite.
3. `verify_ledger()` نظيف بعد كل سيناريو يمسّ المال.
4. الحرّاس الخمسة عشر في `ops/checks/` خُضر.
5. `tasks.md` محدَّثٌ بما نُفِّذ **وبما لم يُنفَّذ ولماذا** (المادة ٦-٦).
6. فرعٌ باسم التاسك، وPR ≤ 400 سطر، ورفعٌ بعد كل تاسك.

**وما يمسّ `apps/money` يراجعه مالك المسار أ وجوباً**، مهما كان كاتبه.
