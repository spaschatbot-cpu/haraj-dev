# TASK 03: شاشة التعديل السريع للعدادات والمواقف (`/auctions/quick-edit`)

## ١. الشاشة والمسار
- مسار الشاشة: `/admin_v2/auctions/quick-edit` و `/admin_v2/auctions/{id}/vehicles/quick-edit`
- الصلاحية المطلوبة: `auction_quick_edit` أو دور `yard_meters` (موظف الساحات).

---

## ٢. الحقول والأعمدة (Inline Grid Interface)
- جدول تعديل سريع يضم كافة سيارات المزاد المختار:
  - رقم اللوت `lot_number` (للقراءة فقط).
  - الماركة والموديل `vehicle_brand` / `model` (للقراءة فقط).
  - رقم اللوحة `Plate_number` ورقم الهيكل `chassis_number` (للقراءة فقط).
  - **حقل العداد `mileage`:** حقل إدخال رقمي مباشر قابل للتعديل اللحظي.
  - **حقل رقم الموقف `id_park`:** حقل إدخال نصي مباشر (مثل A-12, B-04).
  - أزرار: حفظ الصف الفردي (AJAX) + زر "حفظ كل التغييرات دفعة واحدة".

---

## ٣. المشاكل الحقيقية السابقة
1. **تضارب الحفظ الميداني:** موظفان يقومان بتعديل سيارات نفس المزاد في نفس اللحظة فيمسح أحدهما بيانات الآخر دون أن يعلم.
2. **إدخال نصوص في حقل رقمي:** كتابة كلمات مثل "خربان" أو "لا يعمل" في حقل العداد أفسدت الفرز الرقمي للسيارات في التطبيق.

---

## ٤. الشروط والقيود الإلزامية
1. **التحقق من رقمية حقل العداد:** يجب أن يكون المدخل في `mileage` رقماً صحيحاً موجباً حصراً، وتفريغ أي نصوص أو فواصل.
2. **الحفظ الفردي المستقل عبر AJAX:** كل تعديل لصف يُرسل ويُحفظ بصورة ذرية مستقلة دون الحاجة لانتظار أو إعادة تحميل باقي الجدول.
3. **توثيق التعديل:** تسجيل معرف الموظف الذي عدّل العداد والموقف في حقول التحديث الزمني.
