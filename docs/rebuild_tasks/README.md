# حراج واحد — المخطط الشامل لإعادة البناء: شاشات الأدمن ومحركات النظام

> **دليل وثائق إعادة البناء الموجهة للتطوير:**
> يحتوي هذا الفهرس على تصنيف شامل لجميع صفحات الأدمن ومحركات النظام حسب الأهمية ومعدل الاستخدام، مع ربط كل شاشة ومحرك بملف التاسك الخاص به ضمن مراحل التنفيذ (Phases).
