# TASK 03: شاشة تقرير مزايدات مستخدم والتدقيق (`/users/bids-report`)

## ١. الشاشة والمسار
- مسار الشاشة: `/admin_v2/users/bids-report`
- مسار تصدير البيانات: `/admin_v2/users/export-csv`
- الصلاحية المطلوبة: حصرية للمالك (`owner`).

---

## ٢. الحقول والبيانات المعروضة
- **محددات البحث:**
  - بحث برقم الجوال أو رقم الهوية أو معرف المزاد.
- **ملخص التقرير المالي:**
  - إجمالي عدد المزادات المشارك فيها.
  - إجمالي عدد السيارات التي زايد عليها.
  - إجمالي مبالغ المزايدات مع وبدون الضريبة.
  - عدد السيارات التي فاز بها وتمت ترسيتها عليه.
- **جدول التفاصيل الزمني:**
  - رقم المزاد، اسم السيارة، واللوت.
  - السعر المبدئي للعميل.
  - السعر النهائي المسجل.
  - تاريخ وتوقيت آخر تعديل للسعر.
  - نوع الحركة: (زيادة عادية، أو خفض سعر معتمد).

---

## ٣. المشاكل الحقيقية السابقة
- عند اعتراض العميل على خسارة مزاد أو ادعائه بأنه زايد بسعر أعلى ولم يُعتمد، كان البحث في جداول قاعدة البيانات يستغرق وقتاً طويلاً لإثبات تسلسل الأسعار.

---

## ٤. الشروط والقيود الإلزامية
1. **ربط كل مزايدة بسجل التدقيق (`bid_edit_audit`):** عرض التاريخ الزمني لتعديل كل سعر مع توثيق هل تم التعديل من هاتف العميل أم عبر تدخل إداري.
2. **إمكانية التصدير الكامل لـ CSV:** لتزويد الإدارة أو الجهات الرقابية بتقرير مثبت غير قابل للتلاعب عند الحاجة.
