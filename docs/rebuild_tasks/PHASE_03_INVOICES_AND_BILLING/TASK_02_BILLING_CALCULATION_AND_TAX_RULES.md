# TASK 02: حسابات الفاتورة والرسوم والضرائب وفخ ازدواج ضريبة Odoo (Billing Calculation & Tax Rules)

## ١. الهدف ونطاق المهمة
تحديد معادلة الحساب الدقيقة لعناصر فاتورة السيارة المباعة (سعر الترسية، الرسوم الإدارية، ضريبة القيمة المضافة 15%)، وحل الفخ المحاسبي التاريخي الناتج عن ازدواج احتساب الضريبة بين Odoo والتطبيق.

---

## ٢. الأهمية ومعدل الاستخدام
- **الأهمية:** 🔴 حرجة جداً (Tax Compliance & Financial Accuracy).
- **الدافع الميداني:** تسبب عدم التمييز بين مصدر الفاتورة في السابق في فرض ضريبة 15% إضافية فوق مبالغ كانت شاملة الضريبة بالفعل من Odoo، مما حمّل العميل زيادة غير مشروعة بنسبة 15%.

---

## ٣. مكوّنات الفاتورة القياسية ومعادلتها
تتكون فاتورة السيارة من:
1. **سعر الترسية (Hammer Price / Winning Bid):** قيمة المزايدة الفائزة المعتمدة.
2. **الرسوم الإدارية (Admin Fees):** مبلغ ثابت يحدده المزاد أو إعدادات النظام (مثال: 1,500 ر.س لكل سيارة).
3. **ضريبة القيمة المضافة (VAT 15%):** تطبق على سعر الترسية والرسوم الإدارية وفق أنظمة هيئة الزكاة والضريبة والجمارك (ZATCA).

```
سعر الترسية         = Amount
رسوم الخدمة         = Fees
الإجمالي قبل الضريبة = Subtotal = (Amount + Fees)
مبلغ الضريبة (15%)   = VAT = Subtotal × 0.15
الإجمالي النهائي     = Total = Subtotal + VAT = Subtotal × 1.15
```

---

## ٤. فخ مصدر الفاتورة وازدواج الضريبة (The Double VAT Trap)
- **المشكلة القاتلة:**
  - إذا تم إنشاء الفاتورة يدوياً أو محلياً: تكون مبالغ البنود غير شاملة الضريبة، ويجب ضربها في 1.15.
  - إذا تم سحب الفاتورة من Odoo عبر API: فإن Odoo يعيد حقل `total` وهو **شامل الضريبة والرسوم مسبقاً**!
  - إذا قام التطبيق بتطبيق معادلة `Total * 1.15` على فاتورة قادمة من Odoo، ستُحسب الضريبة مرتين!
- **القاعدة الإلزامية في البناء الجديد:**
  - إضافة عمود صريح في جدول الفواتير: `is_vat_inclusive` (أو فحص `source`):
  ```php
  if ($invoiceSource === 'odoo_sync') {
      $grandTotal = $odooTotalAmount; // المبلغ قادم شاملاً بالفعل
  } else {
      $grandTotal = ($bidAmount + $adminFees) * 1.15; // حساب محلي للضريبة
  }
  ```

## ٥. متطلبات الفاتورة الضريبية وفق ZATCA
1. **الرقم التسلسلي للفاتورة الضريبية:** فريد وغير قابل للتكرار.
2. **بيانات المشتري الضريبية:**
   - للأفراد: الاسم ورقم الهوية الوطنية أو الإقامة.
   - للشركات: اسم المنشأة، الرقم الضريبي (15 رقماً تبدأ وتنتهي بـ 3)، رقم السجل التجاري، والعنوان الوطني.
3. **رمز الاستجابة السريعة المشفّر (ZATCA Phase 1 QR Code):**
   - ترميز TLV (Tag-Length-Value) Base64 يحتوي على: (اسم المورد، الرقم الضريبي للمورد، الطابع الزمني، إجمالي الفاتورة، إجمالي الضريبة).
