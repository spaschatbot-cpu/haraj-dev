# R2-01 · دورة الوديعة

```
free ──مزايدة──► held ──دَين──► locked ──سداد──► free
  │                                 │
  └──► refunded                     └──► confiscated
```

## الحالات
| الحالة | المعنى | تُحتسب في الرصيد؟ |
|---|---|---|
| `free` | متاحة للمزايدة أو الاسترداد | ✔ |
| `held` | محجوزة لمزاد يزايد فيه | ✔ |
| `locked` | مقفولة مقابل دَين غير مسدَّد | ✔ |
| `refunded` | خرجت — استرداد | ✖ |
| `confiscated` | خرجت — مصادرة | ✖ |

## قواعد
1. **وديعة واحدة لكل دَين.** لا وديعتان على دَين واحد ولا دَين بلا وديعة إن وُجدت.
2. **القفل يفضّل الحرّة، وإلا يسحب محجوزة من مزاد آخر** (قاعدة المالك د1-ب):
   مزايداته هناك تبقى، لكن لا يزايد جديداً.
3. **التحرير يحتاج سداد كل فواتير المزاد** لا فاتورة واحدة — الفائز بعدة سيارات
   تبقى وديعته مقفولة حتى تُسدَّد كلها.
4. **`releaseRedundantLocks` يفكّ المكرَّر فقط** — لا يفكّ لمجرد أن الدَّين توقّف عن
   الظهور (سيارة أُعيد عرضها تختفي من الحساب مؤقتاً، وليست مسدَّدة).
5. **`void_reason` إلزامي لكل خروج** — وما لا يُثبَت لا يُخمَّن: الغموض يمنع الخصم.
6. **استثناء يدوي**: `linked_auction_id` + `linked_invoice_id` معاً على صفٍّ واحد
   يجعل وديعة تؤمّن دَينين، بلا كود.

- [ ] عدد المقفول ≤ عدد الديون القائمة لكل عميل
- [ ] كل صفّ خارج له `void_reason`
- [ ] سداد آخر فاتورة في المزاد يحرّر الوديعة تلقائياً
