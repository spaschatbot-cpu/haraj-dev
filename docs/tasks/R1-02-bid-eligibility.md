# R1-02 · شروط أهلية المزايد

الأكواد الفعلية التي يردّها `BidApiController::place()` — **بالترتيب**:

| الكود | الشرط | الرسالة للمستخدم |
|---|---|---|
| `VEHICLE_REQUIRED` | لم تُحدَّد مركبة | اختر السيارة |
| `VEHICLE_NOT_LIVE` | المركبة أو المزاد غير مفتوحين | المزاد غير متاح للمزايدة |
| `VEHICLE_AWARDED` | السيارة رُسِيت بالفعل | تم ترسية السيارة |
| `PROFILE_INCOMPLETE` | ملف الشركة ناقص (ZATCA) | أكمل بيانات المنشأة |
| `NO_ACTIVE_SUBSCRIPTION` | لا اشتراك تأمين | اشترك بـ10,000 أولاً |
| `PENDING_REFUND_BLOCKS_BID` | وديعة عليها طلب استرداد قائم | لا يُلغى من التطبيق |
| `NO_FREE_INSURANCE` | لا وديعة حرّة | تأمينك محجوز |
| `LOWER_NEEDS_CONFIRM` | مبلغ أقل من مزايدته السابقة | تأكيد صريح (409) |

## القاعدة الحاكمة: التأمين قبل كل شيء

قبل قبول أي مزايدة يُنادى `InsuranceSettlement::lockUnpaidWinners()`:
كل مزاد منتهٍ عليه دَين غير مسدَّد **يقفل وديعة**. فالمدين تُسحب وديعته إلى دَينه
القديم ولا تبقى له وديعة حرّة لمزايدة جديدة — هذه هي «ثغرة المدين يزايد بالمجان»
مغلقةً. مزايداته القائمة في مزادات أخرى **لا تُلمس**.

## قواعد
1. **الوديعة يجب أن تساوي التأمين الأساسي أو تزيد** — وديعة 1 ريال لا تزايد ولا تؤمّن.
2. **طلب الاسترداد القائم يمنع المزايدة** بنفس الوديعة، ولا يُلغى الطلب من التطبيق:
   أودو هو دفتر الاستردادات.
3. **كل رفض يُسجَّل** بلقطة من حالة الودائع — `/admin_v2/bid-eligibility` يجيب
   «ليه ما يقدرش يزايد» في ثوانٍ، بالقراءة فقط.
4. **خفض المزايدة مسموح بالتصميم** (مزادات مغلقة) لكنه يحتاج تأكيداً صريحاً.

## معايير القبول
- [ ] كل رفض يعطي كوداً ورسالة تقول ما العمل
- [ ] مدين لا يزايد إلا بتأمين جديد
- [ ] لا مزايدة تُقبل على مركبة مرسّاة
