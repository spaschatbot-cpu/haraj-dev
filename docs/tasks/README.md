# خريطة صفحات الإدارة — قائمة المهام وفيزاتها

خريطة إعادة بناء لوحة الإدارة. لكل صفحة ملف مهمة يشرح **ما تفعله** و**الجداول والحقول
التي تحكمها** و**القواعد التي لا يجوز كسرها** عند إعادة بنائها.

كل رقم هنا مقيس من الإنتاج يوم **2026-09-05**، لا مقدَّر:
عدد الطلبات من سجلات nginx (أغسطس + سبتمبر)، وعدد الأسطر والمسارات من الكود،
وأعمدة الجداول وتوزيع قيمها من قاعدة الإنتاج نفسها.

## قواعد تسري على كل فيز

1. **لوحات `admin2/` و`admin3/` مستعمَلة فعلاً** — 4,067 طلباً على `admin2/bills` وحدها.
   لا تُحذف ولا تُهجَّر إلا بعد أن يعمل بديلها بالكامل ويُقاس استعماله.
2. **الجداول المشتركة لا تُعاد تسميتها.** `auctions` · `auction_vehicles` · `bids` ·
   `userss` · `invoices_odoo` · `insurance_deposits` تقرؤها اللوحات القديمة والتطبيق
   وأودو معاً؛ تغيير اسم عمود يكسر مسارات لا تراها.
3. **قبل أي بناء: اقرأ `docs/claude-memory/`** — فيها تاريخ الحوادث. كثير مما يبدو
   تصميماً غريباً هو أثر عطلٍ حقيقي.
4. **التوقيت:** `NOW()` و`date()` بتوقيت UTC، وأوقات المزادات بتوقيت السعودية (+3).
   حوِّل طرفاً واحداً بـ`CONVERT_TZ`، ولا تحوّل الطرفين.
5. **كل تصدير يمرّ بـ`SheetIO`** — تُخرج xlsx افتراضاً وتقرأ xlsx/CSV/XML بالمحتوى
   لا بالامتداد، فالملف المصدَّر يُرفع كما هو.
